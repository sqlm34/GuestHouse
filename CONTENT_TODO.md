# Данные, которые нужно предоставить владельцу

- Телефон для звонков.
- Номер WhatsApp.
- Ссылка или username Telegram.
- Подтверждённые удобства в номерах и на территории.
- Правила проживания.
- Время заезда и выезда.
- Условия предоплаты, если они есть.
- Возможность проживания с животными.
- Embed-код или API-настройки Яндекс Карты с точным маркером.
- ID Яндекс Метрики.
- ID Google Analytics 4.
- Дополнительные реальные фотографии по категориям: дом, территория, двухместные, трёхместные, пятиместные номера, море и окрестности.
